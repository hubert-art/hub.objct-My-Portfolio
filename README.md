## Overview

This repository contains the source code for my personal developer portfolio.

The portfolio was designed to present who I am as a software engineer, the technologies I work with, the projects I have built, and the services I can provide.

My approach combines **software engineering, frontend development, backend architecture, UI/UX design, and product thinking** to create digital experiences that are both functional and enjoyable to use.

## Design Philosophy

I believe good software is more than functional code.

A good product should be:

* **Simple** — Easy to understand and navigate
* **Useful** — Built around real user needs
* **Responsive** — Comfortable to use across different devices
* **Consistent** — Clear visual and interaction patterns
* **Maintainable** — Structured so it can evolve over time
* **Human** — Designed around the people who actually use it

The portfolio itself follows these principles through a clean interface, responsive layouts, reusable visual patterns, subtle motion, and accessible navigation.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/hubert-art/hub.objct-My-Portfolio.git
```

### 2. Navigate into the project

```bash
cd hub.objct-My-Portfolio
```

### 3. Run the project

Because this is a frontend portfolio, you can open `index.html` directly in a browser.

For development, using a local development server is recommended.

For example, with VS Code, you can use **Live Server** or another local static server.

## Deployment
